Missed opportunities for vaccination (MOV) occur when eligible children contact health services but leave without receiving all indicated vaccines. 
We developed an agent-based network model in which included children-caregivers’ dyads, and health workers interact across households and facilities. 
Evidence-based interventions, including status screening, reminders, and caregiver education, were represented as changes to vaccination mechanisms. 
The model was calibrated using approximate Bayesian computation with sequential Monte Carlo (ABC-SMC) against survey data. 
A machine learning surrogate, such as XGBoost, emulated the simulator, enabling rapid exploration, sensitivity analysis, and identification of key MOV drivers. 
Counterfactual scenarios estimated intervention effects with credible intervals, helping immunisation programmes prioritise strategies.
